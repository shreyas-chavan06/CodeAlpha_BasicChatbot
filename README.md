# Basic Chatbot

A simple rule-based chatbot developed using Python.

## Features

- Responds to greetings
- Responds to "How are you?"
- Ends the conversation when the user says "bye"
- Provides a default response for unknown messages
- Runs continuously until the user exits

## Technologies Used

- Python
- Jupyter Notebook

## How to Use

1. Run the notebook.
2. Enter a message when prompted.
3. The chatbot will respond based on the input.
4. Type `bye` to end the conversation.
